# 🎮 TetrisX

一个现代化的俄罗斯方块游戏，基于 [Kofybrek 的版本](https://github.com/Kofybrek/Tetris) 整体重构，迁移到 SFML 3 ，并添加了 UI ，计分系统、排行榜系统和多媒体支持，是复旦大学王雪平老师2025年面向对象程序设计课程大作业。

## 已有特性

- **经典俄罗斯方块玩法** - 7种标准方块类型（I、J、L、O、S、T、Z）
- **幽灵方块预览** - 显示方块落地位置
- **Wall Kick 系统** - SRS（Super Rotation System）旋转规则
- **线条清除动画** - 流畅的消行视觉效果
- **速度递增系统** - 随等级提升游戏速度

## 新增内容

### 整体重构
- **SFML 3.x** 迁移 - 使用最新的 SFML 3.x 版本
- **模块解耦** - 代码结构优化，拆分模块化设计


### 完整UI界面
- **主菜单** - 开始游戏、查看排行榜、退出。支持鼠标输入。
- **游戏界面** - 实时显示分数、等级、行数、连击数
- **排行榜界面** - 格式化显示历史最高分
- **游戏结束界面** - 显示最终分数和返回选项

### 计分与排行榜
- **计分系统**
  - 单行~四行消除不同分数
  - 连击奖励
  - 软降/硬降额外分数
  - 方块放置基础分数
- **等级系统** - 每10行升级，影响下降速度和分数倍数
- **历史排行榜** - 保存前10名最高分记录
- **详细统计** - 游戏时长、放置方块数、消除行数等

### 多媒体体验
- **背景音乐** - 循环播放的BGM
- **音效系统** - 方块放置、消行、游戏结束音效
- **音量控制** - 支持静音（M键）
- **视觉背景** - 添加了背景图片


## 游戏控制

### 基本操作
| 按键 | 功能 |
|------|------|
| **← →** | 左右移动方块 |
| **↓** | 软降（加速下落） |
| **空格** | 硬降（瞬间落地） |
| **C** | 顺时针旋转 |
| **Z** | 逆时针旋转 |

### 菜单操作
| 按键 | 功能 |
|------|------|
| **↑ ↓** | 菜单导航 |
| **Enter** | 确认选择 |
| **ESC** | 返回菜单（排行榜界面） |
| **鼠标** | 点击选择菜单项 |

### 系统功能
| 按键 | 功能 |
|------|------|
| **M** | 静音/取消静音 |
| **Enter** | 游戏结束后返回菜单 |

## 系统要求

### 开发环境
- **CMake** 3.16 或更高版本
- **C++20** 兼容编译器（GCC 10+, Clang 10+, MSVC 2019+）
- **SFML 3.x** 完整安装（Graphics, Window, System, Audio）
